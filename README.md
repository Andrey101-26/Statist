# Statist

Учёт поступлений, резервирование и передача гуманитарной помощи.

**Сайт:** [rey33.pythonanywhere.com](https://rey33.pythonanywhere.com/)

Python 3.11+ · Flask · SQLite · серверные HTML-шаблоны.

## Структура

| Путь | Содержимое |
|---|---|
| `app.py` | Маршруты, формы, CSRF, CSV, проверка `/healthz` |
| `store.py` | Схема SQLite, остатки, транзакции, резервы и выдачи |
| `ui.py` | Шаблоны и оформление |
| `access.py`, `access_ui.py` | Приглашения, вход, роли и экраны доступа |
| `catalogs.py` | Проверка и транзакционный импорт CSV |
| `wsgi.py` | Точка входа хостинга |
| `manage.py` | Инициализация демонстрационных данных |
| `tests/` | Проверки учёта, HTTP, прав доступа и импорта |
| `.github/workflows/tests.yml` | CI на Python 3.11 и 3.12 |
| `docs/DEPLOYMENT.md` | Размещение и обновление сервера |
| `docs/DATA.md`, `samples/` | Подготовка данных и образцы CSV |
| `instance/` | База данных; исключена из Git |

## Разработка

Создать окружение: `python -m venv .venv`.

Активировать: Windows — `.venv\Scripts\activate`; Linux/macOS — `source .venv/bin/activate`.

```sh
python -m pip install -r requirements.txt
python manage.py init-demo
python app.py
```

`init-demo` сохраняет существующие данные. `app.py` — сервер разработки; хостинг использует `wsgi.application`.

## Тесты

```sh
python -m unittest discover -s tests -v
```

Проверки: дефицит, конкурирующие резервы, выдача, отмена, перезапуск, CSRF, роли, приглашения, вход, атомарность CSV и полный HTTP-сценарий.

## Конфигурация

| Переменная | Назначение |
|---|---|
| `STATIST_DATABASE` | Путь SQLite; по умолчанию `instance/statist.sqlite3` |
| `STATIST_SECRET_KEY` | Ключ сессий; по умолчанию сохраняется в метаданных базы |
| `STATIST_PUBLIC_DEMO` | `1` — гостевой просмотр демобазы; `0` — вход обязателен для просмотра |

## Доступ

| Роль | Действия |
|---|---|
| Координатор | Заявки, резервы, отмена, поступления, выдача, справочники и приглашения |
| Сотрудник склада | Просмотр, поступления и выдача |
| Наблюдатель | Просмотр и отчёты |
| Гость | Только просмотр публичной демобазы |

Первое приглашение создаётся владельцем на сервере: `python manage.py invite-owner`. Действует 24 часа и один раз; ссылка не публикуется. Пароль задаёт сам сотрудник. Следующие приглашения создаёт координатор в разделе «Сотрудники».

## Ограничения

Онлайн-версия использует общую вымышленную базу. Изменения требуют входа и соответствующей роли. Для реального пилота нужна отдельная закрытая база.

Целые количества, один склад на заявку, резервирование всего состава. Частичные выдачи, возвраты, партии и межскладские перемещения пока не реализованы.
